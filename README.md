# AnalizadorLCS
Programa para analizar distintos algoritmos LCS - Actividad 1 de la asignatura Diseño Avanzado de Algoritmos del 3er curso del Báchelor en Informática de la Universidad UNIPRO

Ejecución

El programa requiere que los archivos LCS.py y dataset.csv estén en el mismo directorio.

python3 LCS.py bajo Linux
python LCS.py bajo Windows

Desde el menú se pueden ejecutar las pruebas, mostrar los resultados por pantalla y exportarlos a un archivo CSV.
